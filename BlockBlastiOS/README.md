# Block Blast iOS

Native SwiftUI block puzzle game for iPhone and iPad.

## How to run

1. Open `BlockBlastiOS/BlockBlastiOS.xcodeproj` in Xcode 15 or newer.
2. Select the `BlockBlast` scheme.
3. Choose an iPhone simulator or a connected iPhone.
4. Press Run.

If you run on a real iPhone, select your Apple developer team in the target signing settings first.

## Gameplay

- Select one of the three pieces at the bottom.
- Tap the board cell where the top-left corner of the piece should be placed.
- Fill a complete row or column to clear it and earn bonus points.
- A new set of pieces appears after all three pieces are used.
- The best score is saved on the device.
